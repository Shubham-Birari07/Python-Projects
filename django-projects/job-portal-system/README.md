# Job Portal System

## Overview

Job Portal System is a Django-based web application that connects job seekers with employers through an online recruitment platform.

The system enables employers to post job openings while allowing candidates to search, view, and apply for available positions through an intuitive web interface.

---

## Features

- User Registration & Login
- Employer Dashboard
- Job Seeker Dashboard
- Job Posting
- Job Search
- Job Application Management
- Company Information
- Database Integration
- Responsive User Interface

---

## Technologies Used

## Project Workflow

1. User Registration
2. User Authentication
3. Employer Posts Job
4. Job Listings Display
5. Candidate Searches Jobs
6. Candidate Applies for Jobs
7. Employer Reviews Applications
