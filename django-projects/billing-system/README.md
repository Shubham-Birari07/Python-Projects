# Billing System

## Overview

Billing System is a Django-based web application developed to simplify billing and invoice management. The system allows users to manage products, generate bills, calculate totals, and maintain customer transaction records through a user-friendly interface.

---

## Features

- Product Management
- Customer Billing
- Invoice Generation
- Automatic Total Calculation
- CRUD Operations
- User-Friendly Interface
- Database Integration

---

## Technologies Used

- Python
- Django
- HTML
- CSS
- JavaScript
- Bootstrap
- SQLite
- Django ORM

---

## Project Workflow

1. User Login (if implemented)
2. Add Products
3. Select Customer
4. Generate Bill
5. Calculate Total Amount
6. Save Billing Record
7. Display Invoice
